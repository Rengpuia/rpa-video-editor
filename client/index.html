📜 Version History & Changelog
v2.0.0 (Cleanroom Release) CURRENT
October 24, 2026 - Cleanroom Overhaul, Extended Resolutions, Webcam Effects & MCP Support
  • 100% Cleanroom Architecture: Pure independent codebase with zero proprietary code, assets, or trademarks.
  • Extended Multi-Resolution Exporter: 8K Cinema (7680x4320), 4K UHD, 2K QHD, 1080p, 720p, 480p, 9:16 Vertical, 1:1 Square, 4:5 Portrait, 21:9 Ultrawide, plus arbitrary Custom Resolution (Width x Height) with aspect ratio lock and 24/30/60/120 FPS.
  • Callout & Annotation Text Alignment: Full horizontal alignment (Left, Center, Right, Justify) and vertical alignment (Top, Middle, Bottom) across all callout and subtitle bounding boxes.
  • Webcam Video Input & Geometric Mask Effects: Webcam device selector with Circle, Squircle, Hexagon Polygon, Diamond, and Oval masks, custom overlay sizing, borders, soft drop shadows, and horizontal mirror flip.
  • Model Context Protocol (MCP) Support: Full MCP JSON-RPC 2.0 endpoint (/api/mcp) and stdio transport server (mcp_server.js) enabling seamless AI assistant automation (Antigravity, Claude, Cursor).
  • Hardware & Memory Optimization: Desynchronized GPU-accelerated canvas pipelines, idle render loop gating, LRU text metrics caching, and automatic Blob URL garbage collection.
  • Installer & Packaging Pipeline: Inno Setup 6 installer script (installer.iss) and automated GitHub Actions workflow for production releases.
